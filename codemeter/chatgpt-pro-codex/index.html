What Pro reports

The screen fits the plan.

When our first Pro customer set up in September 2026, Pro reported a weekly Codex limit and no 5-hour limit, the same as the Codex CLI showed. Firmware 0.4.1 taught codeMeter to read a plan with one limit.

With one limit, the screen shows one large card: the budget left, a bar, how far into the window you are, and a detail card with the reset time, your pace and the window length. If Pro reports more limits, they appear by themselves. The picture above shows a plan with both.

Read it

Budget left, like the CLI.

  • 5h limit and Weekly limitOne card each, titled the way the Codex CLI's /status titles them.
  • Percent leftCodex shows the budget you have left, so codeMeter does too, with a small left beside it. The blue bar drains like a fuel gauge.
  • Resets and countdownThe reset time and how long until then, like resets 2:00pm in 2h 0m.
  • PaceThe thin line under the bar is time left. If your budget falls behind it, the number and the card outline turn amber, then red.

FAQ

Questions.

Does it work with ChatGPT Pro?

Yes. It shows the Codex limits Pro reports. In our testing that was a weekly limit only, shown as one large card with the budget left.

My Codex CLI says 9% left. Will codeMeter agree?

Yes. Since firmware 0.4.2 a Codex screen shows the budget left, matching the Codex CLI. The number, the bar and the time line all read as remaining.

Does checking use up my Codex limit?

No. codeMeter reads the same usage endpoint the Codex CLI uses for /status. It makes no model calls, so it uses none of your Codex limit.

Can I see Claude and Codex together?

Yes. Choose Claude + Codex at setup. Claude is orange, Codex is blue, and both show percent used so the bars compare.
