How it works

A meter, not a monitor.

  • Runs on its ownIt joins your Wi-Fi and checks every 60 seconds. No computer, no app, nothing in the background.
  • Your sign-in stays on itNo account with us, no server of ours in between.
  • Keeps up with the rulesWhen a plan changes its limits, codeMeter updates itself over Wi-Fi.

FAQ

Questions.

Which AI coding tools does it support?

Claude (Pro, Max, Team, Enterprise) and OpenAI Codex on ChatGPT plans that include it.

Can I switch between them later?

Yes. Hold C about 7 seconds to factory reset, then set it up again and pick another choice. No reflashing.

What do I need?

A paid plan for each account you show (Claude Pro, Max, Team or Enterprise, or a ChatGPT plan with Codex), 2.4 GHz Wi-Fi with a WPA2 password, and, for Claude, a computer once per account to run claude setup-token.

Is there a subscription?

No. You buy the device once. Firmware updates are free and install themselves over Wi-Fi; if an update ever fails to start, it rolls back to the previous version.
