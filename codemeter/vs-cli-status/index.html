FAQ

Questions.

Will codeMeter and the Codex CLI show the same percent?

Yes. Both show the budget left from the same endpoint. On the Claude + Codex screen codeMeter shows percent used instead, so the bars compare.

Does checking use up my Codex limit?

No. codeMeter reads the same usage endpoint the Codex CLI uses for /status. It makes no model calls, so it uses none of your Codex limit.

Does checking use up my Claude limit?

Each check is one tiny request on Anthropic's cheapest model, once a minute. It is a negligible slice of your allowance.

Is a desk display worth it if the usage page is free?

If you check often, or keep hitting a limit mid-task, a screen that is always in view saves the checking. If you rarely look, the free page is enough.
