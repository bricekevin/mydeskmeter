Why

It reads what the plan reports.

codeMeter reads the same usage numbers the Codex CLI's /status uses, and sorts each limit by its length: 5-hour, weekly or monthly. So a plan with a different set of limits should still show whichever ones it reports.

But nobody has run a Business or Enterprise workspace on it yet, so we will not promise it. Ask us before you buy at info@encinitas3d.com.
