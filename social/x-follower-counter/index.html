Straight answer

socialMeter does not count X followers.

If you were looking for an X follower counter, here is why this one leaves X out, and what it can count instead.

Why

X keeps the count to itself.

  • X has no free API tier: reading follower counts is paid, by usage.
  • Checking once a minute, all day, would cost far more than the device itself, every month.
  • So socialMeter leaves X out instead of adding a bill you did not expect.

Counters that do show X followers pay for API access or a data vendor, and pass that cost on.

Instead

What it can count.

If your audience has moved, Bluesky and Mastodon follower counts are free and need only your handle. Video creators can count YouTube subscribers.

  • YouTubeSubscribers

FAQ

Questions.

Will socialMeter ever support X?

Only if X offers a way for a device to read the count without a middleman. Updates are free and install themselves, so if that changes, existing devices get it too.

Is there a workaround for X?

Not one we are willing to ship. The workarounds are a cloud service that holds your login or a paid data vendor, and both can stop working or start costing money.
