On the screen

What it shows for YouTube.

The labels below are the ones printed on the device.

SUBSCRIBERS
Your channel's subscriber count. YouTube rounds it to three significant figures for everyone, so 54,321 shows as 54,300 and moves in steps.
VIEWS
Total views across the channel.
VIDEOS
Public videos on the channel.
N TODAY
The green pill: subscribers gained since the day's first reading, in your time zone.
NEXT MILESTONE
A bar to the next round number (1, 2 or 5 followed by zeros), with how far along you are.
Circle and dot
The circle empties until the next check. The dot is green while the number is live, amber while it shows the last reading, red when something needs a look.

Checks: Every 60 seconds.

What you need

Set up in a few minutes.

Needs a free key

It needs your channel handle or ID and a free YouTube Data API key you make once. Your channel handle or ID and key stay on the device. No account with us, no app.

  1. Find your channel handle or ID
    Your channel handle (the @ is optional), or a UC... channel ID.exampleMyChannel
  2. Get your YouTube Data API key
    1. Go to console.cloud.google.com and create (or pick) a project.
    2. In the search bar, open YouTube Data API v3 and click Enable.
    3. Go to APIs & Services, Credentials, Create credentials, API key.
    4. Copy the key (it starts with AIza) and paste it into the API-key box.
  3. Plug it in and join its Wi-Fi
    Power it with any USB-C cable. Scan the code on its screen (or join the Social Meter-XXXXXX network) and the setup page opens. If it does not, visit 192.168.4.1.
  4. Choose YouTube and fill in one page
    Pick YouTube from the list and type your channel handle or ID, then paste your key into the API-key box.
  5. Pick your home Wi-Fi and save
    Choose your 2.4 GHz Wi-Fi, type its password and tap Save. It restarts and shows your number within about 30 seconds.

FAQ

Questions.

Why does my subscriber count move in hundreds?

YouTube's API rounds subscriber counts to three significant figures for every channel, so a channel with 54,321 subscribers reads 54,300. The device shows exactly what YouTube reports. Views and videos are exact.

Does the YouTube API key cost anything?

No. It is a free Google Cloud key with no billing card. One check a minute uses about 1,440 of the 10,000 free daily quota units.

Can I use my channel ID instead of the handle?

Yes. Type the handle (with or without the @) or the channel ID that starts with UC. Both work.

Can it show live viewers instead?

Yes, that is the YouTube Live setup. It uses the same API key and shows viewers right now while you stream.

Does it need my YouTube password?

No. It reads the count with the free key you make, never your password. The key stays on the device.
