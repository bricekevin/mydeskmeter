On the screen

What it shows for YouTube Live.

The labels below are the ones printed on the device.

VIEWERS NOW
Concurrent viewers on your current live stream. It shows 0 while the channel is not streaming.
VIEWS
Views on the live video.
No today pill
Viewers right now rise and fall, so the device leaves out a daily gain.
NEXT MILESTONE
A bar to the next round number (1, 2 or 5 followed by zeros), with how far along you are.
Circle and dot
The circle empties until the next check. The dot is green while the number is live, amber while it shows the last reading, red when something needs a look.

Checks: Every 60 seconds.

What you need

Set up in a few minutes.

Needs a free key

It needs your channel handle or ID and a free YouTube Data API key you make once. Your channel handle or ID and key stay on the device. No account with us, no app.

  1. Find your channel handle or ID
    Your channel handle (the @ is optional), or a UC... channel ID. Shows 0 when you are not streaming.exampleMyChannelAlready set up the YouTube subscriber counter? This uses the same API key: just paste it again.
  2. Get your YouTube Data API key
    1. Go to console.cloud.google.com and create (or pick) a project.
    2. APIs & Services, Enable APIs, then enable YouTube Data API v3.
    3. Credentials, Create credentials, API key, then copy it into the API-key box.
  3. Plug it in and join its Wi-Fi
    Power it with any USB-C cable. Scan the code on its screen (or join the Social Meter-XXXXXX network) and the setup page opens. If it does not, visit 192.168.4.1.
  4. Choose YouTube Live and fill in one page
    Pick YouTube Live from the list and type your channel handle or ID, then paste your key into the API-key box.
  5. Pick your home Wi-Fi and save
    Choose your 2.4 GHz Wi-Fi, type its password and tap Save. It restarts and shows your number within about 30 seconds.

FAQ

Questions.

What does it show when I am not streaming?

0 viewers, with the dot still green: the check worked, there is just no live stream. It picks the stream up on the next check after you go live.

Will it use up my YouTube API quota?

No. It finds your stream from your channel's recent uploads instead of a search, which costs 2 quota units a check, about 2,880 a day against the free 10,000.

Why is there no "today" number?

Viewers rise and fall during a stream, so a daily gain would not mean much. The device leaves it out for every live count.

Does it need my YouTube Live password?

No. It reads the count with the free key you make, never your password. The key stays on the device.
