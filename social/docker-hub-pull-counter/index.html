On the screen

What it shows for Docker Hub.

The labels below are the ones printed on the device.

PULLS
Total pulls of the repository, from Docker Hub's public API. Large counts show compact, like 2.3M.
STARS
Stars on the repository.
TAGS
Tags published.
N TODAY
The green pill: image pulls gained since the day's first reading, in your time zone.
NEXT MILESTONE
A bar to the next round number (1, 2 or 5 followed by zeros), with how far along you are.
Circle and dot
The circle empties until the next check. The dot is green while the number is live, amber while it shows the last reading, red when something needs a look.

Checks: Every 60 seconds.

What you need

Set up in a few minutes.

Name only

It needs only your repository: no key, no login. Your repository stays on the device. No account with us, no app.

  1. Find your repository
    The repository as user/repo. Official images use library/, like library/nginx.exampleyou/your-app
  2. Plug it in and join its Wi-Fi
    Power it with any USB-C cable. Scan the code on its screen (or join the Social Meter-XXXXXX network) and the setup page opens. If it does not, visit 192.168.4.1.
  3. Choose Docker Hub and fill in one page
    Pick Docker Hub from the list and type your repository. Leave the API-key box blank.
  4. Pick your home Wi-Fi and save
    Choose your 2.4 GHz Wi-Fi, type its password and tap Save. It restarts and shows your number within about 30 seconds.

FAQ

Questions.

Can I watch an official image?

Yes. Official images live under library/, so type library/nginx, library/postgres and so on.

Do I need a Docker Hub token?

No. Pull counts are public for every public repository.

Why is there no live preview for Docker Hub on this page?

Docker Hub's API does not answer requests from web pages, only from apps and devices. The socialMeter asks it directly, so it works on the device.

Does it need my Docker Hub password?

No. Docker Hub image pulls are public, so it needs only the repository.
