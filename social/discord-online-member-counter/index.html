What it shows for Discord.

The labels below are the ones printed on the device.

ONLINE
Members online right now, the same number the server widget shows.
No today pill
Members online rise and fall, so the device leaves out a daily gain.
NEXT MILESTONE
A bar to the next round number (1, 2 or 5 followed by zeros), with how far along you are.
Circle and dot
The circle empties until the next check. The dot is green while the number is live, amber while it shows the last reading, red when something needs a look.

Checks: Every 60 seconds.

What you need

Set up in a few minutes.

Name only

It needs only your server ID: no key, no login. Your server ID stays on the device. No account with us, no app.

  1. Find your server ID
    Your Discord server's numeric ID.example123456789012345678
  2. Turn on the server widget
    1. Open your Discord server, Server Settings, Widget.
    2. Switch Enable Server Widget on.
    3. To copy the server ID: turn on Settings, Advanced, Developer Mode, then right-click the server icon and choose Copy Server ID.
  3. Plug it in and join its Wi-Fi
    Power it with any USB-C cable. Scan the code on its screen (or join the Social Meter-XXXXXX network) and the setup page opens. If it does not, visit 192.168.4.1.
  4. Choose Discord and fill in one page
    Pick Discord from the list and type your server ID. Leave the API-key box blank.
  5. Pick your home Wi-Fi and save
    Choose your 2.4 GHz Wi-Fi, type its password and tap Save. It restarts and shows your number within about 30 seconds.

FAQ

Questions.

Does it show total members or only online?

Members online right now. That is what Discord's public widget offers without a bot, so there is nothing to install on your server.

It says not found. What should I check?

That the server widget is on (Server Settings, Widget) and that you typed the long numeric server ID, not the server name or an invite link.

Can I try it here?

Yes. Type your server ID into See your count below; it reads the same widget the device does.

Does it need my Discord password?

No. Discord members online are public, so it needs only the server ID.
