On the screen

What it shows for GitHub.

The labels below are the ones printed on the device.

FOLLOWERS
Followers of the GitHub account, exact, from GitHub's public users API.
REPOS
Public repositories on the account.
FOLLOWING
Accounts it follows.
N TODAY
The green pill: followers gained since the day's first reading, in your time zone.
NEXT MILESTONE
A bar to the next round number (1, 2 or 5 followed by zeros), with how far along you are.
Circle and dot
The circle empties until the next check. The dot is green while the number is live, amber while it shows the last reading, red when something needs a look.

Checks: Every 2 minutes without a token (to stay inside GitHub's hourly limit), every 60 seconds with one.

What you need

Set up in a few minutes.

Name only

It needs only your GitHub username: no key, no login. Your GitHub username stays on the device. No account with us, no app.

  1. Find your GitHub username
    Your GitHub username (the @ is optional). Organisations work too.exampleyournameOptional: a GitHub personal access token in the key box raises the hourly limit, so it checks every minute instead of every two.
  2. Plug it in and join its Wi-Fi
    Power it with any USB-C cable. Scan the code on its screen (or join the Social Meter-XXXXXX network) and the setup page opens. If it does not, visit 192.168.4.1.
  3. Choose GitHub and fill in one page
    Pick GitHub from the list and type your GitHub username. Leave the API-key box blank.
  4. Pick your home Wi-Fi and save
    Choose your 2.4 GHz Wi-Fi, type its password and tap Save. It restarts and shows your number within about 30 seconds.

FAQ

Questions.

Does it show repository stars?

No. It counts the account's followers, with public repos and following underneath. Stars are not on this screen. For a package's reach, npm weekly downloads or Docker Hub pulls are the closer number.

Do I need a GitHub token?

No. Without one it checks every 2 minutes, which keeps it inside GitHub's anonymous limit. A free personal access token lets it check every minute.

Does it work for an organisation?

Yes. Type the organisation's name; GitHub reports its followers the same way.

Does it need my GitHub password?

No. GitHub followers are public, so it needs only the GitHub username.
