FAQ

Questions.

Does it count GitHub stars?

No. GitHub shows the account's followers, public repos and following. For a package's reach, npm weekly downloads or Docker Hub pulls are the closer number.

Do any of these need a token?

No. GitHub takes an optional personal access token so it can check every minute instead of every two, but it is not required.

Can I flash my own firmware on it?

It runs socialMeter's firmware and updates itself over Wi-Fi. It is built for the count, not as a dev board.
